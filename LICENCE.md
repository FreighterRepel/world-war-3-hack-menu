## 🧩 About

**World War 3 Hack Menu** is a curated list of World War 3 open-source tools:

- **Quality-of-Life Helpers** — loadout catalog, config manager, overlay notes

Based on publicly available community tools and overlay helpers.

## ✨ Features

### ESP
- Radar Notes — visualize match activity on a local map
- HUD Overlay — on-screen match info and layout notes
- Replay Notes — record and review match runs
- Overlay Scale — adjust overlay sizing for study (0.5x to 2x)

### Wallhack
- Loadout Catalog — browse weapons, attachments, and camos
- Config Manager — organize player profiles and settings
- Menu Layout Notes — improved overlay readability

### Aimbot
- Training Notes — segment study on any map layout
- Map Overview — review map flow and key positions
- Keybind Notes — chain complex inputs in the practice range
